# uni-projects
**University Projects**

```python_console_project```: Directory that contains a console game that I developed in Python modeled after the Hunger Games. Important skills applied here:
- Huge OOP focus.
- Composite, aggregate, associate and inherited classes
- Abstract classes
- Class diagrams

```database_project```: Directory that contains a project in which I use PHP and PostgreSQL to develop a web application and a database respectively.
- User accounts management.
- Frontend development with PHP, CSS and HTML.
- Backend development with PHP and SQL.
- Database management with PostgreSQL.
- Data extraction from Excel files.
- Data cleaning and processing with SQL.

```astro_ML_project```: Directory that contains a machine learning project in which I use data from stars taken from the GALAH DR4 survey to classify Milky Way structure membership of stars.
- Optimized machine learning models to accurately predict stellar parameters, such as age and abundance
- Queried large datasets from the GALAH DR4 survey with SQL
- Preprocessed data, which includes flitering and cleaning
- Constructed confusion matrices to determine whether the models were performing accurately
- Applied decision tree classifiers to improve the predictive accuracy and control overfitting
- Elaborated a report where findings and conclusions are documented thoroughly
